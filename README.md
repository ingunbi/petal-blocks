# 꽃잎 블록 · Petal Blocks

아래 조각 세 개를 8×8 판 위로 끌어다 놓고, 가로·세로 한 줄을 채워 지우며 점수를 쌓는 **드래그 블록 퍼즐**입니다. 줄을 이어서 지우면 콤보 배수가 올라가고, 놓을 곳이 없으면 끝납니다. 설치 없이 브라우저에서 실행하고 계정·서버·유료 API가 필요하지 않습니다.

이름, 꽃잎 타일 그림, 꽃밭(색 테마), 규칙의 세부는 모두 이 프로젝트에서 새로 만든 것입니다. ‘조각을 끌어다 줄을 채우는 블록 퍼즐’이라는 장르에서 영감을 받았을 뿐, 다른 게임의 그림·소리·코드를 사용하지 않았습니다. 조각 모양은 널리 쓰이는 폴리오미노(줄·네모·ㄱ자·T·S·Z)입니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 아래 조각을 끌어서 판 위에 놓기 | 조각은 손가락 위쪽에 원래 크기로 떠오릅니다. 놓을 자리와 지워질 줄이 미리 표시됩니다. |
| 놓을 수 없는 곳에서 손 떼기 | 조각은 트레이로 돌아갑니다. |
| `1` `2` `3` | 조각 고르기(키보드) |
| `←` `→` `↑` `↓` / `W` `A` `S` `D` | 고른 조각 옮기기 |
| `Enter` / `Space` | 고른 조각 놓기. 놓으면 다음 조각이 자동으로 골라집니다. |
| `Esc` | 고른 조각 취소, 고른 조각이 없으면 일시정지 |
| `P` | 일시정지 |
| `M` | 소리 켜기·끄기 (기본은 꺼짐) |
| `Enter` / `R` | 결과 화면에서 다시 시작 |

조각은 돌릴 수 없습니다. 그래서 가로·세로 방향마다 조각이 따로 있습니다.

## 규칙

- **판과 조각**: 8×8 판에 조각 세 개가 주어집니다. 세 조각을 모두 놓으면 새 조각 세 개가 나옵니다.
- **줄 지우기**: 가로나 세로 한 줄이 가득 차면 사라집니다. 가로와 세로가 동시에 차면 한꺼번에 지우고, 겹치는 칸은 한 번만 셉니다.
- **점수**: 놓은 칸 수 + 줄 점수 × 콤보 배수. 줄 점수는 한 번에 지운 줄 수 n에 대해 1줄 10, 2줄 30, 3줄 60, 4줄 100 … (`10 × n(n+1)/2`)입니다. 판을 모두 비우면 올클리어 보너스 100점을 받습니다.
- **콤보**: 줄을 지우면 콤보가 1 오르고, 줄을 못 지운 채 조각을 세 번 놓으면 끊깁니다(두 번까지는 이어집니다). 점수 배수는 콤보 횟수와 같고 10배가 상한입니다. 화면 위 콤보 표시가 흐려지면 곧 끊긴다는 뜻입니다.
- **끝**: 남은 조각을 어디에도 놓을 수 없으면 끝납니다.
- **공정한 조각 분배**: 새 조각 세 개는 언제나 ‘어떤 순서로든 모두 놓을 수 있는 묶음’만 나눠 줍니다(줄이 지워지며 생기는 자리까지 계산). 빈 칸이 3칸 이상이면 이 보장이 항상 지켜지고, 판이 많이 차면 작은 조각이 더 자주 나옵니다. 점수가 오를수록 큰 조각이 조금씩 늘어납니다. 다만 순서를 잘못 두면 막힐 수 있습니다.
- **꽃밭(색 테마)**: 지운 줄의 합계가 30·100·250이 되면 깊은 바다·노을 언덕·박하 숲이 열립니다. 줄을 쓰지는 않으므로 한 번 열면 계속 쓸 수 있습니다.
- 최고 기록, 지운 줄 합계, 최대 콤보, 선택한 꽃밭, 소리 설정은 이 브라우저에만 저장합니다. 저장소가 막혀 있어도 게임은 실행됩니다. 계정 간 동기화와 서버 순위표는 없습니다.

`?seed=숫자`를 주소에 붙이면 같은 조각 순서를 다시 만날 수 있습니다(예: `?seed=7`).

## 개발

Node.js 22 이상을 권장합니다.

```powershell
npm ci
npm run dev        # http://127.0.0.1:5173
npm test           # 자동 테스트(36개)
npm run build      # dist/ (상대 경로 빌드)
npm run preview
```

`dist/`는 상대 경로로 빌드되므로 독립 배포와 포털의 `games/petal-blocks/` 하위 경로 모두에서 실행됩니다.

### Cloudflare

`wrangler.jsonc`는 `dist/`를 Cloudflare Workers 정적 자산으로 제공하는 설정입니다. 계정 정보와 토큰은 저장소에 넣지 않습니다.

```powershell
npm run dev:cloudflare     # 빌드 후 Workers 런타임에서 로컬 실행
npm run check:cloudflare   # 빌드 후 배포 설정 검사(dry-run, 로그인 불필요)
npm run deploy:cloudflare  # 빌드 후 배포(wrangler login 필요)
```

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/shapes.js` | 조각 모양 목록(방향별 37종), 줄 마스크, 작은 조각 목록 |
| `src/engine.js` | 판·조각·점수·콤보의 순수 규칙. 놓기 판정, 줄 지우기 계산, 세 조각 풀이기(`isDealable`), 조각 분배(`dealTray`) |
| `src/layout.js` | 화면 배치와 손가락 위치 → 격자 칸 변환(논리 너비 360, 높이 640~800) |
| `src/renderer.js` | 캔버스 그리기: 타일, 미리보기, 지워지는 애니메이션, 꽃잎 입자 |
| `src/main.js` | 입력(포인터·키보드), 화면 상태, 효과·소리 연결, 저장 |
| `src/themes.js`, `src/storage.js` | 꽃밭 정의와 해금, 브라우저 저장(값마다 검증) |
| `src/audio.js` | 외부 음원 없는 효과음(기본 꺼짐) |
| `src/bot.js` | 테스트 전용 자동 플레이어(화면에서는 쓰지 않음) |
| `src/rng.js` | 시드로 같은 조각 순서를 만드는 난수 |
| `src/*.test.js` | 엔진·조각·저장·배치 자동 테스트 |
